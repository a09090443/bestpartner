> 適用版本：**0.1.8-SNAPSHOT** ｜ 最後更新：**2026-07-30**

## 這份手冊怎麼來的

每一個操作步驟與畫面都取自**實際跑過的 E2E 測試**：步驟來自測試確認表中通過的案例，畫面直接引用該次測試的證據截圖（`docs/test-confirmations/e2e-shots/`），不另存副本。
沒有測試證據的畫面一律標記為 `📷 待補畫面`，不以文字臆測補上。

## 更新這份手冊

UI 或流程行為改變時，**先**更新 `docs/e2e-test-plan.md` 並跑一輪 `e2e-test-confirmation` 取得新截圖，**再**用 `operation-manual` skill 翻新對應章節。
順序顛倒會產生「新的說明配舊的畫面」，比缺畫面更難察覺。
